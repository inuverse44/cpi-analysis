# 分析計画書：消費者物価指数で見る、この数年の物価とお米

データ解析の見本として、公開データを使った分析を、計画から再現手順まで公開する。

## 1. 目的

| ID | 目的 |
| --- | --- |
| G-01 | 依頼を考えている人に、データ解析をどう進め、何を渡せるかを具体的に見せる |
| G-02 | 誰でも同じ結果を再現できる形にする（データの出所、計算の手順、検証を公開する） |

## 2. 問い

| ID | 問い | 目的 |
| --- | --- | --- |
| Q-01 | 物価は、2020 年からどれくらい、いつごろ上がったか | G-01 |
| Q-02 | お米の値段は、どう動いたか。お米を使った身近な食品にも広がったか | G-01 |

## 3. データ

| ID | データ | 内容 | 出所 |
| --- | --- | --- | --- |
| D-01 | 消費者物価指数 全国 中分類・品目別 月次（2020 年基準） | 2020 年 1 月〜最新月。2020 年平均＝100。各系列のウエイトを含む | 総務省統計局「消費者物価指数」 https://www.stat.go.jp/data/cpi/1.html （ファイル：`https://www.stat.go.jp/data/cpi/2020/csv/zmi2020aa.csv`） |

- 2026 年 7 月分から 2025 年基準の指数の公表が始まった。2025 年基準の系列は 2025 年 1 月以降しかないため、2020 年からの動きを途切れずに見られる 2020 年基準の系列を使う。
- 取得した時点のファイルを `data/raw/` にそのまま保存し、取得日と SHA-256 を `data/raw/SOURCES.md` に記録する。
- 系列は名前ではなく**類・品目符号**で指定する。同じ名前（例：「総合」「米類」）が、ファイル内の別の分類表にも現れるため。

## 4. 手法

| ID | 手法 | 定義 |
| --- | --- | --- |
| M-01 | 2020 年平均比 | 指数そのもの（2020 年平均＝100）。「2020 年と比べて何倍か」として読む |
| M-02 | 前年同月比（%） | （当月の指数 ÷ 前年同月の指数 − 1）× 100。季節による変動を除いて、上がるペースを見る |
| M-03 | 年平均 | 暦年 12 か月の指数の単純平均。12 か月そろわない年は出さない |
| M-04 | 山の時期 | 前年同月比が最も大きかった月 |

- 指数は公表値（小数第 3 位まで）をそのまま使い、表示のときにだけ丸める。
- 図は 1 枚あたり 4 系列までにする（配色の見分けやすさを検証した範囲）。うるち米 A・B、弁当 B、すし（弁当）B は、図には出さず表（O-05）に載せる。
- O-04 は、お米の値上がり（前年同月比で最大 +100% 程度）とほかの食品（同 +10% 前後）で幅が大きく違うため、前年同月比ではなく指数で比べる。
- 統計局が公表する前年同月比は、公表時の端数処理の違いから、ここでの計算と小数第 1 位でずれることがある。

## 6. 検証

| ID | 検証 | 根拠 |
| --- | --- | --- |
| V-01 | 2020 年の各系列の年平均が 100 になる（± 0.05） | 基準年の定義 |
| V-02 | 2025 年平均の総合（S-01）が、公表値 111.9 と一致する（小数第 1 位で丸めて） | 総務省統計局の公表値（2020 年＝100） |
| V-03 | 保存したデータの SHA-256 が `SOURCES.md` の記録と一致する | 取得したデータの同一性 |
| V-04 | 読み込み：月がそろって連続している（欠けや重複がない）、使う符号がすべて存在する | データの形の前提 |
| V-05 | 前年同月比：最初の 12 か月は値を持たない、手計算の例と一致する | M-02 の定義 |
| V-06 | 加工済みデータ（O-06）と要約（O-05）が、コードから毎回同じものとして作り直せる | G-02 |

## 7. 再現の手順

```sh
uv sync
uv run cpi-analysis          # データの検証 → 集計 → 図と表 → REPORT.md
uv run pytest                # V-01〜V-06
```

新しい月のデータを取り込むときは `uv run cpi-analysis fetch` で `data/raw/` を更新し、`SOURCES.md` の取得日と SHA-256 も書き換える。
